# Game assets

Place optional PNG image files in this folder using these exact names:

| Filename | Used for |
| --- | --- |
| `player.png` | Player character |
| `Cars/<category>/<car-name>.png` | Standard traffic vehicle; one file is chosen at random for each spawned car |
| `train.png` | Train obstacle |
| `Roads/TopRoad.png` | Upper cap of a contiguous road section |
| `Roads/MiddleRoad.png` | Interior row of a contiguous road section |
| `Roads/BottomRoad.png` | Lower cap of a contiguous road section |
| `grass.png` | Grass-row background/tile |

The game currently draws simple coloured placeholder shapes. These names reserve
the asset locations for when image loading is added.
